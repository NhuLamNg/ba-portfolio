Trustify Data Engineer May 2025 – Aug 2025

Data Migration Platform · client: Trustonic

Moved customers of a device-financing and phone-locking service from the legacy platform (V2) to the next-generation platform (V3), in a way that is safe, verifiable and reversible.

  • Analysed how admin configuration and user permissions worked in V2 and wrote the V2-to-V3 role and permission mapping. Identified permission gaps and proposed how each should be handled.
  • Defined the transformation rules from DynamoDB to PostgreSQL for admin and platform settings (including each customer's custom properties and UI colour scheme) and for the TAC device-model catalogue.
  • Designed the rollback path that lets a customer's migration be reversed: it removes their migrated device data across 6 tables and archives what was removed.
  • Made incremental runs safe to repeat by excluding already-migrated devices, so re-runs never create duplicates.
  • Merged tenant creation and its automated validation into one job, cutting runtime by about 30% (2m33s → 1m47s), and tagged every job by owner, project, environment and team for cost tracking.
  • Worked in a 6-person team and took part in code reviews.

BA skills used: as-is analysis of a legacy system · data mapping · gap analysis · defining rollback and acceptance conditions
